IPC Lib Contracts

Documentación visual y offline del sistema de contratos binarios canónicos para IPC.

Versión

2.1.1 — pre-release

Arquitectura documental

La documentación fuente permanece en README.md, DSL.md, docs/ y docs/wiki/. Esta carpeta contiene únicamente su representación HTML estática.

Principios

  • Contrato binario canónico.
  • Identidad mediante BLAKE3-256.
  • Validación explícita y rechazo seguro de entradas inválidas.
  • Conformidad cruzada entre Rust, C++ y Kotlin.
  • Documentación sin CDN ni JavaScript externo.
